# Requerimientos funcionales del sistema

## 1. Stock
1. El sistema debe permitir registrar materiales (nombre, tipo, caracteristica, cantidad disponible, precio, categoría).
3. El sistema debe permitir modificar y eliminar materiales.
4. El sistema debe permitir consultar el stock disponible.
5. El sistema debe permitir filtrar el stock por nombre, tipo, categoría.
6. El sistema debe generar alertas de stock bajo.
7. El sistema debe mantener un historial de precios de los materiales.

## 2. Gestión de productos y servicios
1. El sistema debe permitir crear productos (nombre, costo de producción, precio de venta, categoría).
2. El sistema debe permitir crear servicios (nombre, costo de servicio)
3. El sistema debe permitir modificar y eliminar productos.
4. El sistema debe permitir modificar y eliminar servicios.
5. El sistema debe permitir calcular automáticamente el precio de venta, considerando: costo de materiales y porcentaje de ganancia (30% o 40%)
6. El sistema debe permitir editar y eliminar productos.
7. El sistema debe permitir consultar productos y servicios.
